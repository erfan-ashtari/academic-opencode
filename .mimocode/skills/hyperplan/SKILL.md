# Hyperplan - Adversarial Planning

5 hostile critics analyze your plan simultaneously:

1. **Security Critic** - Identifies vulnerabilities
2. **Performance Critic** - Finds bottlenecks
3. **Architecture Critic** - Evaluates design decisions
4. **Edge Case Critic** - Finds missing cases
5. **Maintenance Critic** - Evaluates maintainability

## Usage

Type `hyperplan` in chat to activate.
