# Tech Debt Audit

Categorizes debt by type:

- **Code Debt**: Duplicated code, complex functions
- **Architecture Debt**: Tight coupling, poor design
- **Test Debt**: Missing tests, poor coverage
- **Documentation Debt**: Missing or outdated docs
- **Dependency Debt**: Outdated or vulnerable deps

## Usage

```bash
/tech-debt-audit
```
