# GitHub Triage

This skill provides read-only analysis of GitHub issues and pull requests.

## Usage

```bash
gh issue view <issue-number>
gh pr view <pr-number>
gh issue list
gh pr list
```

## Analysis Areas

- Bug reports
- Feature requests
- Questions
- Documentation issues
