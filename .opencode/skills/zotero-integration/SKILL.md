# Zotero Integration Skill

Integrate with Zotero for reference management, library synchronization, and collection organization.

## Features

- Library search and retrieval
- Collection management
- Reference import/export
- BibTeX synchronization
- Tag and annotation management

## Usage

```bash
# Search Zotero library
/search-zotero "transformer attention"

# Import to collection
/import-to-zotero --collection "NLP Papers" --query "deep learning"

# Export collection
/export-zotero --collection "NLP Papers" --format bibtex
```
