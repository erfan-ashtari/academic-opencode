# Email Composer Skill

Draft professional academic emails for correspondence with professors, collaborators, and journal editors.

## Email Types

| Type | Purpose |
|------|---------|
| Inquiry | Ask questions, request information |
| Collaboration | Propose or discuss collaboration |
| Submission | Paper submission cover letters |
| Follow-up | Follow up on previous correspondence |
| Thank you | Thank reviewers, mentors, collaborators |

## Features

- Professional tone adjustment
- Template-based drafting
- Context-aware content
- Multiple formality levels

## Usage

```bash
# Compose inquiry email
/compose-email --to "professor@university.edu" --topic "research collaboration"

# Compose follow-up
/compose-email --to "editor@journal.com" --topic "manuscript status" --follow-up
```
